#+TITLE: Emacs 键盘宏完全指南
#+DATE: 2026-03-30
#+OPTIONS: toc:2 num:nil

* 基础操作

| 快捷键        | 功能                             |
|---------------+----------------------------------|
| F3            | 开始录制                         |
| F4            | 结束录制（再按一次 = 执行一次）  |
| C-u 50 F4     | 重复执行50次                     |
| C-u 0 F4      | 执行无限次，直到宏内操作失败停止 |
| C-x C-k e     | 进入宏编辑器（可修改已录制的宏） |
| C-x C-k n     | 给宏命名（命名后可永久保存）     |
| C-x C-k C-i   | 宏内插入自动递增计数器           |

* 核心思维

宏本质是：*录制你的按键序列然后重放*。

凡是"我要对很多行/很多地方做同样的操作"，就是宏的场景。

关键点：宏里可以包含搜索，这让宏从"重复N次"变成"跳到每个匹配处执行操作"。

#+begin_quote
一句话判断法："我刚才做的这个操作，还需要对N个地方做一遍"
—— 立刻想到宏。不需要事先计划，发现重复时随时录！
#+end_quote

* 场景一：批量格式化行（最常用）

需求：把字段名批量加上前缀和后缀

原始内容：
#+begin_example
userName
userAge
userEmail
#+end_example

目标：
#+begin_example
private String userName;
private String userAge;
private String userEmail;
#+end_example

操作步骤：
1. 光标移到第一行行首
2. =F3=          开始录制
3. =C-a=         跳到行首
4. 输入 =private String =
5. =C-e=         跳到行尾
6. 输入 =;=
7. =C-n=         移到下一行
8. =F4=          结束录制
9. =C-u 99 F4=   对剩余行重复执行

* 场景二：宏 + 搜索（高手核心用法）

需求：文件里多处需要做同样的编辑，但每处要微调，不能用全局替换。

操作步骤：
1. =F3=    开始录制
2. =C-s=   搜索目标关键词
3. 对这一处做修改（任意复杂的编辑操作）
4. =F4=    结束录制
5. 反复按 =F4=，每次跳到下一个匹配并执行

#+begin_quote
重点：搜索 + 编辑的组合可以无限重复，处理散落在文件各处的同类问题。
这是宏最强的用法。
#+end_quote

* 场景三：宏 + 自动递增编号

需求：自动生成序号列表
#+begin_example
item_001
item_002
item_003
#+end_example

操作步骤：
1. 在 =*scratch*= 里先执行：=(setq my-counter 0)= 然后 =C-x C-e=
2. =F3=            开始录制
3. 输入 =item_=
4. =C-x C-k C-i=   插入计数器（自动递增）
5. 回车换行
6. =F4=            结束录制
7. =C-u 100 F4=    生成100行

* 场景四：处理 CSV / 表格数据（提取某列）

需求：把 CSV 每行的第二列提取出来

原始：
#+begin_example
张三,18,北京
李四,25,上海
#+end_example

操作步骤：
1. =F3=
2. =C-a=     行首
3. =C-s ,=   搜索第一个逗号，然后删除前面的内容
4. =C-s ,=   搜索第二个逗号
5. =C-k=     删到行尾
6. =C-n=     下一行
7. =F4=
8. =C-u 99 F4=

* 场景五：代码重构 / 批量加模板

需求：给多处方法调用加 try-catch 包裹，每处结构相同但内容不同，正则替换做不到。

做法：
1. 录制宏：搜索方法名 → 选中整行 → 粘贴模板 → 调整缩进
2. 对每处执行 =F4=

#+begin_quote
这类操作用正则替换根本做不到，宏是唯一方案。
#+end_quote

* 高手进阶用法

** 命名宏 + 永久保存

#+begin_src emacs-lisp
;; 1. 给当前宏命名
;; C-x C-k n  输入名称，如 format-java-field

;; 2. 导出为 elisp 代码（放入 init.el 永久保存）
(insert-kbd-macro 'format-java-field)
#+end_src

** 宏绑定快捷键

#+begin_src emacs-lisp
;; 把宏绑定到 F5
(global-set-key (kbd "<f5>") 'format-java-field)
#+end_src

高频使用的宏直接变成自定义命令。

** 宏编辑器（录完不满意，进去改某一步）

| 快捷键      | 功能                           |
|-------------+--------------------------------|
| C-x C-k e   | 打开宏编辑器（像编辑文本一样） |
| C-c C-c     | 保存修改                       |

* 什么时候不用宏

| 情况               | 更好的工具                  |
|--------------------+-----------------------------|
| 固定字符串全局替换 | =M-%=（query-replace）      |
| 正则替换           | =C-M-%=（regexp replace）   |
| 修改多处相同变量名 | LSP rename / iedit-mode     |
| 每列数据独立处理   | 矩形操作（=C-x r= 系列）    |

* 学习建议

- *第1天*：练 F3/F4 基础录制，找一个有重复行的文件操作10次
- *第2天*：练"宏+搜索"组合，处理散落各处的同类修改
- *第3天*：练 =C-u 0 F4= 无限执行 + 自动停止
- *第1周后*：尝试给一个常用宏命名并保存到 init.el

#+begin_quote
核心习惯：发现第二次重复操作时，立刻按 F3 开始录制。
不要等到第十次才想起用宏。
#+end_quote
