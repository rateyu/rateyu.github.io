* 当前配置存在的问题总览

** 严重问题
1. *API Key 硬编码* — =.emacs= 第189行有 OpenAI 密钥明文，如果此文件被 git 追踪会泄漏
2. *快捷键冲突*（共3处）：
   - =C-c n=：eyebrowse-next 和 org-capture "n" 互相覆盖
   - =C-c p=：eyebrowse-prev 和 projectile-command-map 互相覆盖
   - =C-c t=：注释里的 toggle-truncate-lines 和 org-capture "t" 冲突

** 冗余/重复问题
- =find-file-in-project= 和 =projectile= 功能重叠，保留 projectile 即可
- =ido= + =smex= 已被安装的 vertico/orderless/consult 替代，但新的还没配置
- =company= 和 vertico 生态可以共存，但 company 配置不完整

** 调试配置遗留（应删除）
#+begin_src emacs-lisp
(setq debug-on-error t)      ; 日常使用不需要
(setq tramp-verbose 10)      ; 会导致 TRAMP 极慢，日常应为 1 或注释掉
#+end_src

** 缺失（进阶清单里的）
- =which-key= — 已装但未配置
- =expand-region= — 已装但未配置
- =vertico= / =orderless= / =marginalia= / =consult= — 已装但未配置

;;; ============================================================

(setq package-archives

  (package-refresh-contents)
  (package-install 'use-package))
(require 'use-package)
(setq use-package-always-ensure t)  ; 自动安装未安装的包


;;; ============================================================
;;; 1. 编码：统一 UTF-8
;;; ============================================================
(prefer-coding-system 'utf-8)
(set-default-coding-systems 'utf-8)
(set-terminal-coding-system 'utf-8)
(set-keyboard-coding-system 'utf-8)
(set-language-environment "UTF-8")


;;; ============================================================
;;; 2. UI：外观与基础行为
;;; ============================================================
(tool-bar-mode -1)
(menu-bar-mode -1)
(scroll-bar-mode -1)

(setq dired-use-ls-dired nil)

;; 字体（Monaco 130，可按需修改）
(set-face-attribute 'default nil
                    :family "Monaco"
                    :height 130)

;; 显示行号（编程模式下）

;;; ============================================================
;;; 3. which-key：快捷键提示（新增，强烈推荐）
;;; ============================================================
(use-package which-key
  :config

  (setq which-key-idle-delay 1.0))


;;; ============================================================

  :bind

  ("C-x b"   . consult-buffer)        ; 替代 switch-to-buffer
  ("M-y"     . consult-yank-pop)      ; 替代 yank-pop
  ("C-c p s" . consult-ripgrep))      ; 项目内容搜索

;; smartparens：括号自动配对

  :hook (prog-mode . smartparens-mode))

;; 代码补全
(use-package company
  :hook (prog-mode . company-mode)
  :config

        company-minimum-prefix-length 1
        company-selection-wrap-around t))

;; yasnippet：代码片段
(use-package yasnippet
  :config (yas-global-mode 1))

;; 选中后直接替换（内置）
(delete-selection-mode 1)


;;; ============================================================
;;; 6. 导航与跳转

;; 标记环：跳转历史（内置）
;; C-SPC C-SPC 设置标记，C-u C-SPC 跳回上一个位置

;; xref：代码定义和引用跳转（内置）
